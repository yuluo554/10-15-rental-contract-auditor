# 口径（与 plan/RELEASE-M6.md §4 一致）：
#   - 可复跑的是「同 dist → 同 zip 字节」这一步（ZIP_STORED + 条目 sort + 固定 date_time）。
#     本版两个 zip 的确定性均已实测：`build_release.py --check` → RELEASE_ZIP_DETERMINISTIC_OK。
#   - **exe 构建本身不承诺跨机字节一致**（PyInstaller 会嵌入时间戳/路径），
#     故 exe 的 sha256 只是"本机这次构建"的指纹，不作跨机比对承诺。
#   - RELEASE ASSET 两行记**附件名**（不是本地 `_scratch/` 路径）：`_scratch/` 在
#     `.gitignore` 内，换机或清掉该目录后台账里的路径就不存在了；附件名在任何机器上都对得上
#     GitHub Release。取文件：gh release download v0.1.1 --repo yuluo554/10-15-rental-contract-auditor
#   - 前两行 exe 的路径同理只是**本机构建产物**的引用（口径见上一条：不作跨机比对）。
